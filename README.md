## Project Workflow

### 1. Data Loading

* Imported the dataset into Python using Pandas.
* Examined dataset structure and data types.

### 2. Exploratory Data Analysis (EDA)

* Analyzed data distribution and patterns.
* Identified trends, correlations, and outliers.
* Created visualizations for better understanding.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicates.
* Corrected data types and formatting issues.
* Prepared data for analysis.

### 4. SQL Analysis

* Loaded the cleaned dataset into MySQL.
* Wrote SQL queries to answer business-related questions.
* Performed aggregations, filtering, and trend analysis.

### 5. Power BI Dashboard

* Connected Power BI to the processed dataset.
* Created interactive dashboards and visual reports.
* Added KPIs, charts, and filters for data exploration.

### 6. Reporting & Presentation

* Documented key findings and business insights.
* Prepared a professional presentation using Gamma.

1. Clone the repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook and run all cells.
4. Import the cleaned dataset into MySQL.
5. Execute the SQL queries provided in the `sql` folder.
6. Open the Power BI file to explore the dashboard.
7. Review the report and presentation for detailed insights.
